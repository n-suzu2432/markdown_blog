# はじめての投稿

ブログを開設しました。このサイトは Next.js と Markdown で構築した静的サイト（SSG）です。

## なぜ WordPress をやめたのか

以前は WordPress を使っていましたが、次のような問題がありました。

- ページの読み込みが遅い
- プラグインの管理が煩雑になる
- セキュリティアップデートに追われる

## SSG に移行してよかったこと

静的サイトに切り替えてから、これらの問題がすべて解消されました。

1. **高速**：HTML ファイルを直接配信するのでレスポンスが速い
2. **安全**：データベースがなく攻撃対象が少ない
3. **無料**：Vercel に無料でホスティングできる
